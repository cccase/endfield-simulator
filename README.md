# アークナイツ：エンドフィールド ローテーション＆SPシミュレーター

『アークナイツ：エンドフィールド』のスキル回し（ローテーション）とSP・EP（必殺技チャージ）の挙動を検証・計算するためのシミュレーターです。

## 主な機能
- **キャラクター編成**: 最大4人までのパーティー編成、凸数・必殺チャージ効率の調整
- **スキルパレット**: 戦技・連携技・必殺技・返還SPのドラッグ＆ドロップおよびクリックによるタイムライン配置
- **タイムライン機能**: 
  - サイクルごとのスキル順序設定・並び替え
  - サイクル追加・複製・削除
  - 各サイクルの消費SP・返還SPの自動集計
- **シミュレーション・計算**:
  - 実質消費SP（返還SP控除後の通常SP消費）に応じた全体EP蓄積計算
  - 連携技によるキャラ固有のEP回復
  - オクギのEPロック・解除ギミック
  - スーの戦技1→戦技2の順序チェックと警告表示
  - 各キャラの必殺技発動必要チャージ効率（USG）の逆算表示
- **共有・保存**:
  - URLによる編成・タイムライン状態の共有
  - 画像書き出し機能（html2canvas）

## ファイル構成
```text
├── index.html              # メインUI
├── style.css               # スタイル定義
├── app.js                  # シミュレーションロジック・UI制御
├── data/
│   └── characters.json     # キャラクター初期データ・デフォルト編成
└── image/                  # キャラクターアイコン
```
